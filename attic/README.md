# Archive: QART pipeline set up and MatNeo SIP

## TL;DR

This document outlines set up steps and auditing of the MatNeo SIP QART data which guided development of this reproducible analytical pipeline. All data quality issues were solved by Q4 in FY 2024/25. The pipeline no longer produces analytical outputs for MatNeo SIP. None of these scripts are used in the current version of the pipeline.

## SharePoint Set up

- *retroactive_setup_site_folders.R* - Created folders for each PSC in a designated SharePoint location to save excel templates and returned data. It only required running once because the SharePoint location has been stable since.

## Relevant files on SharePoint

The files below are now stored in a sub-directorate of the master files folder named `matneo-sip-archive`.

- *readme.txt* - this was a readme uploaded in each site folder when `setup_site_folders.R` was run.
- *MatNeoSIP.xlsx* - file received from business support with several tabs where most of the QART process used to take place. The quarterly data from 2021/22 Q1 to 2024/25 Q3 is in the 'Data' tab. 'QART info' was used to calculate aggregations on the data. The remaining tabs were dedicated to make the plots for the analytical output (a slide deck).
- *mat_neo_qart_cleansed_upto_2024_25_Q3.csv* - A corrected version of data in `MatNeoSIP.xlsx` which addresses data quality issues explained below.
- *matneo_overview.png* - Overview of the MatNeo programme. This picture went in the slide deck generated by `qart_slides.qmd`. This file was downloaded from SharePoint by `run-quarto.R`*.*

## Retroactive Fixes to MatNeo SIP data

Retroactive corrections to data up to 2024/25 Q3 were needed to create data ready for automation. These corrections addressed DQ issues whereby data were recorded for both legacy and successor organisations several quarters *after* an organisation change had taken place (effectively generating a case of duplicated organisations in the data set). A secondary DQ issue was the use of outdated organisation names. There's no need to re-run the scripts below:

- *retroactive_org_changes.R* - Read previous submissions from `MatNeoSIP.xlsx` and updated HIN names using `hin_names.csv`. More importantly, this script checked the NHS trusts present in the data up to 2024/25 Q2 and determined whether an organisation was legacy via a series of calls to the [ODS API](https://digital.nhs.uk/developer/api-catalogue/organisation-data-service-ord). This script generated 2 output files `psc_icb_trust_lookup.csv` and `discrepancies_lookup.csv`.

- *retroactive_data_cleanse.R* - This script used `discrepancies_lookup.csv` to resolve conflicts in data points with an outdated name or where where data was recorded simultaneously for *both* a legacy organisation and its successor (i.e., a legacy carry over).

  The name fixes were addressed easily, as it was just replacing outdated names with correct ones. The legacy carry overs were more complex as data points from multiple organisations needed to be compared and a value for each MatNeo intervention had to be chosen. The output of this file was a cleansed version of `MatNeoSIP.xlsx` - i.e., a file with quarterly data from 2021/22 Q1 to 2024/25 Q3 (`mat_neo_qart_cleansed_upto_2425_Q3.csv`). Subsequent submissions (until 2526 Q4) were appended to these cleansed data.

## MatNeo SIP output

*qart_slides.qmd* - Read cumulative data file produced in `process/append_data` - i.e., cleansed data plus new submissions. Analytical output was a PowerPoint slide deck visualising data for each MatNeo SIP intervention. Outputs are stored in the archive sub-directorate of the output folder in SharePoint.
